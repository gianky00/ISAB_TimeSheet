# SyncroJob - Design System
Documentazione degli standard visivi per Gemini.

## Palette Colori (Material 3)
Definita in `src/gui/design/colors.py`.

- **Primary**: #009688 (Teal) - Usato per azioni principali e brand.
- **Secondary**: #673AB7 (Purple) - Usato per elementi di supporto.
- **Surface**: #FFFFFF (White) - Sfondo schede e pannelli.
- **Background**: #FAFAFA (Off-white) - Sfondo applicazione.

## Componenti UI Standard
- **Sidebar**: Navigazione a icone con badge di stato.
- **StatusCard**: Header dei pannelli con indicatore di attività bot.
- **Toast**: Notifiche a scomparsa per feedback immediato.
- **LogWidget**: Visualizzazione streaming dei log di esecuzione.

## Asset
- Icone: Formato `.svg` in `assets/icons/`.
- Stili: File `.qss` in `assets/styles/`.
